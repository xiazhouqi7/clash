# Clash Downloads

> A lightweight download distribution page maintained as part of the Xiazhouqi project system.

This repository powers a simple, mobile-friendly download page for selected Clash clients and related platform builds.

## Website

https://clash.xiazhouqi7.com

## Repository contents

- `index.html` — download landing page
- `CNAME` — custom-domain configuration
- Releases — downloadable application files used by the page

## Design direction

The page follows Xiazhouqi's restrained utility-page approach: clear hierarchy, low visual noise, direct download actions and mobile-first layout.
