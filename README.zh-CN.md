# Clash Downloads｜下周七分发页

**简体中文** · [English](./README.md)

> Xiazhouqi 项目体系中的一个轻量下载分发页面

这个仓库用于维护一个简洁、移动端友好的 Clash 客户端下载页，把常用平台版本集中整理在一个入口中，减少查找和跳转成本。

## 在线页面

https://clash.xiazhouqi7.com

## 仓库内容

- `index.html` — 下载入口页
- `CNAME` — 自定义域名配置
- Releases — 页面实际调用的安装文件

## 设计方向

页面遵循 Xiazhouqi 的工具页设计原则：层级清楚、视觉噪音低、主操作直接、移动端优先，不用过多装饰抢占内容注意力。
